Jetson Local Tutor — Run Flags Reference
=========================================

QUIZ MODE
---------

Basic run (all defaults):
    python app.py quiz --deck deck.apkg

Inspect deck field names before running:
    python app.py quiz --deck deck.apkg --inspect-fields

Manual field mapping:
    python app.py quiz --deck deck.apkg --question-field Definition --answer-field Word
    python app.py quiz --deck deck.apkg --question-field Front --answer-field Back


RECORDING MODES
---------------

Auto-stop on silence (default):
    python app.py quiz --deck deck.apkg --record-mode auto

Press Enter to stop:
    python app.py quiz --deck deck.apkg --record-mode enter

Fixed duration:
    python app.py quiz --deck deck.apkg --record-mode fixed --duration 10


AUTO MODE TUNING
----------------

Set max recording duration:
    python app.py quiz --deck deck.apkg --record-mode auto --duration 30

Set how long silence must last before stopping (default 1.2s):
    python app.py quiz --deck deck.apkg --record-mode auto --silence-duration 1.5

Set minimum time before silence detection kicks in (default 1.0s):
    python app.py quiz --deck deck.apkg --record-mode auto --min-record-duration 2.0

Set energy threshold manually (int16 RMS scale, ~300-3000):
    python app.py quiz --deck deck.apkg --record-mode auto --energy-threshold 800

Noisy room — raise threshold and require longer silence:
    python app.py quiz --deck deck.apkg --record-mode auto --energy-threshold 1200 --silence-duration 2.0

Quiet room — lower threshold and shorter silence window:
    python app.py quiz --deck deck.apkg --record-mode auto --energy-threshold 300 --silence-duration 1.0

Combine all auto tuning flags:
    python app.py quiz --deck deck.apkg --record-mode auto \
        --duration 45 \
        --silence-duration 1.5 \
        --min-record-duration 1.5 \
        --energy-threshold 600


ENTER MODE TUNING
-----------------

Set max duration before auto-stop (if Enter not pressed):
    python app.py quiz --deck deck.apkg --record-mode enter --duration 30


FIXED MODE TUNING
-----------------

Set exact recording duration:
    python app.py quiz --deck deck.apkg --record-mode fixed --duration 8



SESSION PERSISTENCE
-------------------

Start a new tracked session (saves progress to deck.apkg.session.json):
    python app.py quiz --deck deck.apkg --resume

Resume a previous session (continues from next unanswered card):
    python app.py quiz --deck deck.apkg --resume

Wipe session and start over with a fresh shuffle:
    python app.py quiz --deck deck.apkg --resume --reset-session

Reset session without starting a new one:
    python app.py quiz --deck deck.apkg --reset-session

Resume with all TTS and auto-mode flags:
    python app.py quiz --deck deck.apkg --record-mode auto --resume \
        --speak-question --speak-feedback


TTS (SPOKEN FEEDBACK)
---------------------

Speak feedback after each grade:
    python app.py quiz --deck deck.apkg --speak-feedback

Speak the question aloud before recording:
    python app.py quiz --deck deck.apkg --speak-question

Speak both question and feedback:
    python app.py quiz --deck deck.apkg --speak-question --speak-feedback


MULTI-LANGUAGE SUPPORT
----------------------

Set deck language (resolves STT language, Piper model, and grader language automatically):
    python app.py quiz --deck spanish.apkg --language es
    python app.py quiz --deck french.apkg  --language fr
    python app.py quiz --deck german.apkg  --language de

With TTS (question and feedback spoken in the target language):
    python app.py quiz --deck spanish.apkg --language es \
        --speak-question \
        --speak-feedback

Override just the STT language (e.g. deck is English but speaker is non-native):
    python app.py quiz --deck deck.apkg --language en --stt-language en

Override the Piper voice model path explicitly:
    python app.py quiz --deck spanish.apkg --language es \
        --piper-model ~/piper/models/es_ES-sharvard-medium.onnx

All language flags together:
    python app.py quiz --deck spanish.apkg \
        --language es \
        --stt-language es \
        --piper-model ~/piper/models/es_ES-davefx-medium.onnx \
        --speak-question \
        --speak-feedback

With session resume and follow-ups:
    python app.py quiz --deck french.apkg \
        --language fr \
        --speak-question \
        --speak-feedback \
        --resume \
        --followups

Language resolution order (highest priority first):
    1. --stt-language  (overrides --language for STT)
    2. --piper-model   (overrides language-specific TTS default)
    3. --language      (sets all three: STT, Piper model, grader language)
    4. env/defaults    (PIPER_MODEL env var / built-in en_US-lessac model)

Supported --language codes (built-in defaults):
    en   English     es   Spanish     fr   French     de   German

For unlisted languages, use --stt-language and --piper-model explicitly.

NOTE: The STT server uses tiny.en (English-only) by default.
For non-English STT, set WHISPER_MODEL=tiny on the Jetson before starting the server:
    WHISPER_MODEL=tiny uvicorn server:app --host 0.0.0.0 --port 8000

Piper model files must be downloaded manually.
See: https://github.com/rhasspy/piper/releases for available voices.
Place .onnx and .onnx.json files in ~/piper/models/<lang>/ on the Jetson.


ADAPTIVE FOLLOW-UPS
--------------------

Enable follow-up questions (triggers only on incorrect answers):
    python app.py quiz --deck deck.apkg --followups

With TTS (follow-up spoken aloud, response spoken after grading):
    python app.py quiz --deck deck.apkg --speak-question --speak-feedback --followups

With session resume and all flags:
    python app.py quiz --deck deck.apkg \
        --speak-question \
        --speak-feedback \
        --resume \
        --followups

Note: --followups is OFF by default. Without it, behavior is unchanged.
      At most one follow-up is asked per card. No recursive follow-ups.
      Follow-up results do not affect scores or retry scheduling.


FREEFORM DIAGNOSTIC MODE
-------------------------

Basic freeform:
    python app.py freeform

Set fixed recording duration (env var):
    RECORD_DURATION=8 python app.py freeform


STT STANDALONE TEST
--------------------

Test STT service with a WAV file:
    python tests/test_stt_transcribe.py recording.wav


LLM STANDALONE TEST
--------------------

Test Ollama with a prompt:
    python tests/test_llm_generate.py "I have been studying Python for three months."


GRADER STANDALONE TEST
-----------------------

Offline (no Ollama):
    python tests/test_grader_prompt.py

Live grading test (Ollama required):
    python tests/test_grader_prompt.py --live


DOCKER — STT CONTAINER
-----------------------

Build:
    docker build -t jetson-stt:latest ./services/stt

Run on Jetson with GPU:
    docker run --rm --runtime nvidia --gpus all -p 8000:8000 jetson-stt:latest

Check STT service health:
    curl http://localhost:8000/health


OLLAMA
------

Check Ollama is running:
    curl http://localhost:11434/api/tags

Pull model if missing:
    ollama pull qwen2.5:1.5b
